# My Wakeel - AI Legal Assistant for Pakistan

![My Wakeel UI Screenshot](https://img.freepik.com/free-vector/lawyer-concept-illustration_114360-7488.jpg)

My Wakeel is an AI-powered legal assistant specifically designed for the Pakistani legal system. Built with Google's Gemini 2.0 Flash model, it provides comprehensive legal guidance, document analysis, and case law references tailored to Pakistan's laws and regulations.

## Features ✨

- **Instant Legal Answers**: Get accurate responses to legal questions specific to Pakistan
- **Document Analysis**: Upload legal documents for summarization and key point extraction
- **Case Law Research**: Access Pakistani case laws with relevant analysis
- **Contract Review**: Identify unfavorable clauses in contracts
- **Legal Procedures**: Understand court processes and requirements
- **24/7 Availability**: Always-on legal assistance

## Technologies Used 🛠️

- **Frontend**: HTML5, CSS3, JavaScript
- **UI Framework**: Bootstrap 5
- **AI Integration**: Gemini API (2.0 Flash model)
- **Markdown Processing**: Marked.js
- **Fonts**: Google Fonts (Manrope)
- **Icons**: Font Awesome
